# WPF Sorting Visualization

This project is a **sorting visualization tool** developed using **WPF (Windows Presentation Foundation)**. It allows users to configure and visualize different sorting algorithms applied to graphical elements.

## Features
- **Sorting Algorithms**: Choose from multiple sorting methods to see how they process data in real-time.
- **Graph Customization**: Adjust the number of elements, shapes, styles, and other visual aspects.
- **User Controls**: 
  - **Stop**: Halt the sorting process at any time.
  - **Sort**: Execute the selected sorting algorithm.
  - **Generate**: Create a new set of graphical elements.
- **Animation & Effects**: Customize animation styles, easing functions, and transitions.

## Configuration Options
The left-side menu provides a variety of customization options:
- **General Settings**: Number of elements, border thickness, column radius, and sorting speed.
- **Initial Arrangement**: Choose between inverted or random starting positions.
- **Animation Settings**: Define animation types, easing functions, and transition modes.
- **Color Customization**: Assign colors for correct, incorrect, and swapping elements.

## Technologies Used
- **C# & .NET**: Core logic and backend development.
- **WPF**: UI development for interactive visualization.
- **MVVM Pattern**: Ensuring separation of concerns and maintainability.

## Getting Started
1. Clone the repository:
   ```sh
   git clone https://github.com/DevLukab/SortingWPF.git
   ```
2. Open the project in **Visual Studio**.
3. Build and run the application.
